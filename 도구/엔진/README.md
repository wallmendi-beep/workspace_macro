# RegiMacro 엔진 — 사용 안내

변환기(`..\wem변환기.ps1`)가 만든 매크로 JSON(구간·클립)을 읽어 실제로 재생하는 PoC 실행 엔진입니다.

## 구조 (보완은 각 파일만 수정하면 됩니다)

| 파일 | 역할 |
| --- | --- |
| `RegiMacro.ahk` | 메인 진입: 설정 로드, 핫키 등록, 타이머 구동 |
| `Lib\Json.ahk` | 경량 JSON 파서 (외부 라이브러리 없음) |
| `Lib\Player.ahk` | **상태머신·재생 엔진** (정지/실행중/일시정지, 구간 이동) |
| `Lib\Studio.ahk` | 스튜디오 UI (다크 테마 3분할: 구간 목록 · 클립 타임라인 · 속성 패널) |
| `config.ini` | 핫키·간격·모드 설정 (사용자 커스텀 지점) |

## 설치 · 실행

1. AutoHotkey v2 설치 → https://www.autohotkey.com/ (v2 다운로드)
2. `RegiMacro.ahk` 더블클릭 → 변환 결과 폴더에서 `_초안.json` 선택
3. 인디케이터 창이 뜨면 핫키로 조작

## 안전 원칙 — 반드시 읽으세요

- **기본값은 모의 모드(DryRun=1)**: 실제 마우스·키보드 입력이 전혀 없습니다. 로그와 화면 표시만으로 동작을 검증하는 단계입니다.
- 실제 입력 모드로 바꾸려면 `config.ini`에서 `DryRun=0`. 이후에는 **반드시 등기 시스템 실제 화면에서 소규모 검증부터** 하세요.
- 언제든 `End` 키 또는 ⏹ 버튼으로 정지할 수 있습니다.

## 제어 방법

| 입력 | 동작 |
| --- | --- |
| `Ctrl+Alt+R` (트리거) | 시작 / 실행 중이면 일시정지 토글 |
| `Pause` | 일시정지 |
| `Scroll Lock` | 재개 |
| `Home` | 첫 구간 처음으로 |
| `End` | 정지 |
| `PgUp` | 다음 구간 건너뛰기 |
| `PgDn` | 이전 구간으로 돌아가기 |
| `Ctrl+Alt+I` | 인디케이터 창 표시/숨김 |

물리 키가 없는 키보드는 인디케이터 하단 버튼으로 동일 조작 가능합니다.
핫키가 시스템과 충돌하면 `config.ini`의 `[Hotkeys]`를 수정하세요.

## 알려진 제한 (PoC v0.1)

- Insert(편집모드) 미구현 — 에디터 완성 후 연결 예정
- 클립별 간격(`interval`)은 변환기가 아직 채우지 않으므로 기본 2초 적용
- 마우스 좌표는 절대좌표(Screen) 기준 — 해상도가 다른 PC에서는 어긋남(공유 시 주의, 요구사항 정의서 §9 참조)
- 한 번에 하나의 매크로만 로드

## 검토 포인트 (모의 모드 실행 후)

1. 구간 분할이 실제 업무 단계와 맞는지
2. 클립 순서가 실제 화면 흐름과 같은지
3. "입력:" 문구가 실제 시스템에 넣던 내용과 일치하는지 (특히 영문 추정으로 나온 부분)
